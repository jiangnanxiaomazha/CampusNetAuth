# 校园网自动认证工具（电脑版）

自动连接校园网 WiFi 并完成门户认证的 Windows 工具。

## 功能
- 开机静默运行，电脑没网时自动连接校园网并认证
- 有网时绝不抢网，全程无窗口
- 支持任意学校（填写本校登录网址和 WiFi 名称即可）
- 支持运营商选择（移动/联通/电信/校园内网）
- 支持优先频段选择（5GHz/2.4GHz）
- 支持不可用时段（凌晨/节假日不折腾）
- 一键检查更新

## 使用
1. 解压后双击「校园网自动认证配置工具.exe」
2. 填写本校登录网址、WiFi名称、账号、密码、运营商
3. 点「保存校园网配置」
4. 点「开启WiFi自动连接」

## 检查更新
配置界面点「检查更新」，自动从本仓库下载最新版本。

## 文件说明
- `campus_auth.ps1` - 主脚本（自动连接+认证）
- `config_gui.ps1` - 配置界面
- `campus_auth.exe` - 静默启动器
- `校园网自动认证配置工具.exe` - 配置界面启动器
- `version.json` - 版本信息（检查更新用）
